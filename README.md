# CS330-Computational-Graphics-and-Visualization

How do I approach designing software? 

Throughout this project I learned how important it is to break down a design into smaller parts and understand how each component contributes to the overall result. When creating my 3D desk scene, I started by focusing on the different shapes I would need to represent the objects in my reference image. I used basic shapes to create objects such as the laptop, books, and pencil holder before moving on to applying textures and lighting. My approach was to build on what I had already completed throughout each milestone rather than trying to create the entire scene at once. I feel like this helped me better understand the design process because I could focus on what I was learning at that particular point. I can definitely see myself using this approach in future projects, especially when working on something that initially seems outside of my comfort zone. 

How do I approach developing programs? 

One of the most important things I learned throughout this course was how much testing and making adjustments contribute to developing a program. I feel like camera movement was one of the areas I understood the most because I was able to use the assigned keyboard controls, including WASD and QE, to navigate my scene and verify different aspects of my project. I also implemented controls to switch between perspective and orthographic views. Throughout the milestones, I made changes to the code as I developed the shapes, added textures to objects such as the laptop and books, and experimented with different lighting options. I feel like lighting was probably one of the areas I needed more practice with because I focused more on creating the objects and applying textures rather than getting the lighting exactly how I wanted it. As I progressed, I became more comfortable making changes, testing the results, and going back to make adjustments when something did not appear the way I intended. 

How can computer science help me in reaching my goals? 

As I continue working toward my computer science degree, I feel like the skills I developed throughout this course will help me better understand how different components of a program work together. This was my first time creating something as extensive as a 3D scene, and I created it to the capacity in which I understood the material. I definitely want to continue building on what I have already created because I feel like making the scene more realistic as I learn more about lighting, textures, and computational graphics will better showcase my understanding. Professionally, I can see these skills being useful when developing software that involves interactive environments or visual elements. Even if I do not pursue a career specifically in computer graphics, I feel like the experience I gained from working through troubleshooting problems and improving my code will be useful in other areas of software development.
